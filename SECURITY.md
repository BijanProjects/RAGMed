# Security policy

RAGMed Clinic is an educational demo, not a medical service, but security is taken seriously:
see the [security audit](docs/security-audit.md) for what was tested, found and fixed.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
([private vulnerability reporting](https://github.com/BijanProjects/RAGMed/security/advisories/new)).
Do not open a public issue.

Please include what you found, how to reproduce it, and its impact. You can expect an
acknowledgement within a few days.

## Scope

- In scope: the code in this repository and the live demo at ragmed.bijanroudini.com.
- Out of scope: denial-of-service and load testing against the live demo (it runs on free tiers),
  social engineering, and the third-party services it uses.

Please do not enter real personal health information into the demo.
